# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the Oikos Random Number Generator, please report it responsibly.

Please **do not** disclose security vulnerabilities publicly until they have been reviewed and, where appropriate, fixed.

### Preferred Contact

**Email:** [oikonomikos1989@gmail.com](mailto:oikonomikos1989@gmail.com)

### Alternative Contact

**X (Twitter):** @oikosback

When reporting a vulnerability, please include:

* A clear description of the issue.
* The affected version or commit.
* Steps to reproduce the problem.
* Expected behaviour.
* Actual behaviour.
* Any relevant logs, screenshots, or proof-of-concept code.

Please do **not** report security vulnerabilities through public GitHub Issues.

Thank you for helping improve the security and reliability of the Oikos Random Number Generator.
